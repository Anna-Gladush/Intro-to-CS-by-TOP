## Первый уровень

### Квадраты чисел (Squares Array)

Условие: Дано целое число n. Нужно вернуть массив квадратов чисел от 0 до n - 1.

Входные данные: n — целое число.

Выходные данные: Массив целых чисел.

Ограничения: 1 <= n <= 10000

Пример:

Вход: n = 5

Выход: [0, 1, 4, 9, 16]

### Переворот строки на месте (Reverse String In-Place)

Напишите функцию reverse_string(s), которая переворачивает входной массив символов s на месте без использования дополнительной памяти (O(1) extra space).

Примеры ввода и ожидаемого вывода:

---

Input: s = ["h","e","l","l","o"]

Output: ["o","l","l","e","h"]

---

Input: s = ["H","a","n","n","a","h"]

Output: ["h","a","n","n","a","H"]

---

Ограничения:
Массив s может содержать только английские буквы.

1 ≤ len(s) ≤ 10^5

Нельзя использовать дополнительный массив для хранения результата.

### Удаление нулей из массива (Remove Zeros)

Дан массив целых чисел. Напишите функцию, которая возвращает новый массив, содержащий все элементы исходного массива, кроме нулей, с сохранением порядка оставшихся элементов.

Входные данные:
nums — массив целых чисел (длина от 0 до 10⁴).

Выходные данные:
Новый массив целых чисел без нулей, порядок элементов сохранён.

Ограничения:

0 <= nums.length <= 10000

-10^6 <= nums[i] <= 10^6

Пример:

Вход: []
Выход: []

Вход: [0]
Выход: []

Вход: [1, 0, 0, 2]
Выход: [1, 2]

### Заглавные буквы слов в строке (Capitalize First Letter of Each Word)

Условие:

Напишите функцию, которая принимает строку из одного или нескольких слов, разделённых пробелами, и возвращает строку, в которой первая буква каждого слова сделана заглавной, а остальные буквы слова остаются без изменений.

Входные данные:

s — строка, содержащая слова, разделённые одним пробелом (может быть пустой)

Выходные данные:

Строка, где первая буква каждого слова — заглавная, остальные символы слова не изменяются

Ограничения:

0 <= длина s <= 10^4

Строка состоит из строчных и заглавных латинских букв и пробелов

Слова разделены ровно одним пробелом, без начальных/конечных пробелов (если не оговорено иначе в примерах)

Примеры:

Вход: "hello world";
Выход: "Hello World"

Вход: "already Capitalized";
Выход: "Already Capitalized"

Вход: "";
Выход: ""

Вход: "a";
Выход: "A"

### Каррированное сложение (Curried Add)

Условие:

Реализуйте функцию add(a), которая принимает одно число и возвращает другую функцию, принимающую второе число. Итоговый вызов возвращает сумму двух чисел.

Входные данные: два числа a и b, передаваемые через каррирование: add(a)(b)

Выходные данные: число — сумма a + b

Ограничения:

-10^6 <= a, b <= 10^6

a и b — целые числа

Пример:

Вход: add(3)(5)
Выход: 8

Вход: add(-1)(1)
Выход: 0

Вход: add(0)(0)
Выход: 0

### Форматирование числа с разделителями тысяч (Format Number With Thousands Separator)

Условие:
С сервера приходит цена товара как целое число (например, 12345678). Нужно написать функцию, которая преобразует это число в строку, где группы из трёх цифр (считая от конца числа) разделены апострофом '.

Входные данные:
price — целое число в диапазоне от 1 до 2^31 - 1.

Выходные данные:
Строка — то же число, но с апострофами между группами по три цифры, считая справа.

Ограничения:

1 <= price <= 2147483647

### Слова с заданным префиксом (Words With Given Prefix)

Условие:

Дана строка s, содержащая слова, разделённые пробелами, и строка prefix. Напишите функцию, которая возвращает список всех слов из s (в порядке их появления, с повторениями), которые начинаются с prefix.

Входные данные:

s — строка со словами, разделёнными одним пробелом (может быть пустой)

prefix — строка-префикс для поиска (может быть пустой строкой)

Выходные данные:

Массив/список строк — все слова из s, начинающиеся с prefix, в исходном порядке, включая повторы

Ограничения:

0 <= длина s <= 10^5

0 <= длина prefix <= 100

Слова состоят из строчных и заглавных латинских букв

Если prefix — пустая строка, все слова считаются подходящими

Пример:

Вход: s = "ab abc def abc xyz ace ab cab", prefix = "ab"
Выход: ["ab", "abc", "abc", "ab"]

Вход: s = "hello world", prefix = "z"
Выход: []

Вход: s = "", prefix = "a"
Выход: []

### Преобразование массива свойств в объект (Array to Object Mapping)

Условие
С бекенда приходит массив объектов. Каждый объект содержит два поля:

name — название свойства;

value — значение свойства.

Необходимо написать функцию, которая преобразует такой массив в один объект, где каждый name становится ключом, а соответствующий value становится значением.

Если в массиве несколько объектов с одинаковым name, нужно использовать значение из последнего такого объекта.

Входные данные
Массив объектов вида:

[
{ name: "width", value: 10 },
{ name: "height", value: 20 }
]
Выходные данные
Объект, где ключи — это значения поля name, а значения — это значения поля value.

Ограничения

0 <= arr.length <= 10 000
name — непустая строка
value — любое примитивное значение: number, string, boolean, null
Если name повторяется, используется последнее значение
Пример
Вход

[
{ name: "width", value: 10 },
{ name: "height", value: 20 }
]
Выход

{
width: 10,
height: 20
}
