### Квадраты чисел (Squares Array)

Условие: Дано целое число n. Нужно вернуть массив квадратов чисел от 0 до n - 1.

Входные данные: n — целое число.

Выходные данные: Массив целых чисел.

Ограничения: 1 <= n <= 10000

Пример:

Вход: n = 5

Выход: [0, 1, 4, 9, 16]
